== Description ==

Thème WordPress personnalisé pour FNMNS Occitanie - Landing page moderne et performante pour organisme de formation certifié Qualiopi.

**Caractéristiques :**
* Design responsive et moderne
* Optimisé SEO (Schema.org, Open Graph, Twitter Cards)
* Accessibilité (WCAG)
* Performance optimisée
* Template de page landing personnalisé

== Installation ==

1. Téléchargez le dossier du thème
2. Compressez le dossier "THEME_WORDPRESS_FNMNS" en fichier ZIP
3. Dans WordPress Admin, allez dans **Apparence > Thèmes**
4. Cliquez sur **Ajouter** puis **Téléverser un thème**
5. Sélectionnez le fichier ZIP et cliquez sur **Installer maintenant**
6. Activez le thème

== Utilisation ==

1. Créez une nouvelle page dans WordPress
2. Dans les attributs de page, sélectionnez le template "Landing Page FNMNS"
3. Le contenu de la landing page sera automatiquement affiché
